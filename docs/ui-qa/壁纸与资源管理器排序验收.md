# 壁纸与资源管理器排序验收

Task IV-SHELL-01；2026-11-07。实现源码提交`8bd16de`；从`c5beda1`后独立工作树开发。仅本地功能与验收，不安装、发布或push。

## 行为

- Windows右键新增“设为桌面壁纸”。后台使用原始8位像素保存静态PNG，通过`IDesktopWallpaper.SetWallpaper`应用所有显示器，保留布局；动画取点击时当前帧，DDS取Mip 0，透明区域与黑色合成，HDR明确拒绝。原图不改写。结果窗口显示成功或具体错误，居中避开顶栏。
- 单目录索引通过`IShellWindows → IShellBrowser → IFolderView.Items(SVGIO_ALLVIEW | SVGIO_FLAG_VIEWORDER)`读取匹配文件夹窗口的实际顺序，保留日期/大小/名称及升降序。右键“刷新文件夹排序”重新读取；悬停显示来源。没有窗口时使用Windows自然名称排序；递归模式按相对路径自然排序；多窗口排序冲突/读取失败显式说明并使用默认顺序。未出现在视图中的新文件排末尾。
- Explorer枚举最多25万项、图片最多5万项，路径预算32 MiB；后台执行，不阻塞UI。Shell RPC/磁盘响应时长由系统决定，不保证所有网络路径的响应时间。
- 保存壁纸使用独立文件、保留完整尺寸，失败清理新快照；成功后仅清理上一张本工具生成的统一壁纸，不删除用户原图和多显示器各自的壁纸。

## 复现入口

从项目根运行，Rust工具链应在任务进程PATH可用，原生AVIF依赖仍沿用项目构建工具：

```powershell
cargo test --release --workspace --locked
cargo check --workspace --locked
cargo build --release --bin imageview --locked
python -B -m unittest discover -s tools/tests -p test_*.py
```

Explorer专项：打开测试文件夹，通过该窗口Document.SortColumns设置`prop:System.ItemNameDisplay;`、`prop:-System.ItemNameDisplay;`、`prop:+System.Size;`、`prop:-System.Size;`、`prop:+System.DateModified;`或`prop:-System.DateModified;`，回读实际属性。设置`IV_EXPLORER_TEST_ROOT`和以`|`分隔的`IV_EXPLORER_TEST_ORDER`，运行：

```powershell
cargo test --release -p iv-viewer explorer_order::tests::live_explorer_view_order -- --ignored --exact
```

UI复用`tools/ui-qa/neumorphic_smoke.py`及`Temp/ui-latest/shell-actions-880.json`、`shell-actions-1280.json`，使用`--isolated-profile`。原生壁纸往返复用`tools/ui-qa/wallpaper_restore_smoke.py --binary <当前EXE> --output <验收输出> --input <测试PNG> --actions <菜单动作JSON> --commit <构建源码commit>`；脚本仅接受明确输入，备份/恢复壁纸与轮播配置。详细日志在`Temp/ui-latest/`和`Temp/wallpaper-*.log`。
