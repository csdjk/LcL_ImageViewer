# 打开所在目录验收（IV-P1-N05）

用户明确要求资源管理器入口直接打开当前文件所在目录。

## 实现

源码 `14c50ac`：右键项改名为“打开所在文件夹”，当前图像路径先转绝对路径再取父目录，确认目录存在后作为一个原生路径参数传给 `explorer.exe`。删除旧 `/select,<文件路径>` 字符串拼接。不经过cmd/PowerShell，不手动加引号，不使用有损显示字符串作为操作路径。打开失败在现有错误提示中说明，不再忽略错误。

父目录存在时，即使已经缓存的图片随后被删除仍可打开其目录。没有更改图像解码/Shader/鼠标手势/玻璃导航/1秒隐藏/文件关联。

## 分支验证

- `cargo test --workspace --offline`：29 passed / 0 failed；workspace check与Debug构建通过。
- 5项新增测试覆盖相对文件名、相对子目录、单独目录参数、目录缺失、Windows根目录/中文/空格/标点/UNC路径构造。

## 复现

```powershell
python tools/ui-qa/open_folder_smoke.py --binary <当前imageview.exe> --source test_images/gradient.png --output ui-verify-shots/folder-new-run --commit <构建源码提交> --theme light --width 880 --height 560
```

输出目录必须不存在。运行会创建测试输入、打开并核验目录，再关闭本次新创建的Explorer窗口。

## 边界
