# 菜单与图片快捷键验收（IV-P1-N06）

## 用户需求与实现

精简右键菜单，增加A/D切图，并完成上一条未执行的Delete删除修复。
菜单现在保留复制像素（可用时）、复制路径、打开所在文件夹、删除图片、图像属性、像素检查器、打开文件及设置。
移除重复的上一张/下一张、视图缩放/适配、通道、主题、动画和Mip菜单入口；对应工具栏、鼠标和快捷键功能保留。
A/左箭头上一张，D/右箭头下一张；首末仍不循环；Ctrl/Shift/Alt组合、文字输入焦点、菜单与属性/设置/检查器窗口不触发查看器快捷键。两侧按钮tooltip同步提示A/D。

Delete只响应无修饰键的首次按下，不响应长按连发或Shift+Delete；确认弹层绑定当前文件路径、长度和修改时间，取消/Esc不改变文件，操作时屏蔽背景控件和导航。
确认后在STA后台线程用IFileOperation回收文件，FOFX_RECYCLEONDELETE与PreDeleteItem回调拒绝非回收操作，不提供永久删除回退。取消/失败保留当前画面并显示错误。成功后清理缓存/忽略已删除的迟到预读结果，显示原下一张，末尾回退前一张，删完回到空态。

## 复现

```powershell
cargo test --workspace --offline
cargo check --workspace --offline
cargo build -p iv-viewer --offline
cargo build --release -p iv-viewer --offline
python -B tools/ui-qa/menu_controls_smoke.py --binary target/release/imageview.exe --output ui-verify-shots/menu-controls-new-run --commit <实际构建提交> --theme dark --width 880 --height 560
```

该脚本要求新的输出目录，自动创建专用测试图并使用隔离QA profile；不会选择用户图片，也不会关闭已有查看器。输出report.json记录精确回收站匹配、hash和截图数量。
