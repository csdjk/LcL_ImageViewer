# 主画布编辑与常用变换（IV-EDIT-02）

## 交互方案

取消独立编辑 Window；进入编辑后，原生图片窗口直接切换为顶部上下文工具栏、主画布和底部状态/保存栏。画布不再被压缩在浮动预览框内。退出编辑恢复原查看器，保留源文件和原有查看功能。

- 移动：滚轮以鼠标为中心缩放，左键拖动；其他工具下空格加拖动、中键或右键平移。F 适配，0/1:1 实际大小。视图变换不参与导出。
- 裁剪：主画布框选、移动、八个边角手柄、X/Y/宽高输入，方向键1px/Shift方向键10px；支持自由、原图比例及常用横竖比例。Enter应用、Esc取消草稿。
- 旋转与翻转：正反90°旋转、水平/垂直翻转，以及任意角度旋转。任意旋转扩展为透明边界，静止后的预览使用与导出相同的像素算法。
- 分辨率：像素宽高、比例锁定、50%/100%/200%及平滑/最近邻。显式应用后更改实际像素尺寸，与底栏的视图百分比区分。
- 编辑按顺序应用，每一步以当前图像为输入；撤销/重做、重置全部，存在草稿时切换工具先提示应用或丢弃，退出前保护未保存内容。

## 数据与资源边界

原始 RGBA 快照不可变；90°旋转、镜像和无缩放裁剪逐字节保留，包括Alpha=0下隐藏RGB。平滑缩放及任意角度旋转按Alpha加权，预览网格和通道显示不写入图片。

另存为新8位RGBA PNG，不覆盖原图或已有目标。沿用已有临时文件完整写入、no-replace发布及失败清理。动画仅编辑当前帧，DDS使用Mip0，HDR浮点拒绝编辑；不保留原格式、ICC、图层或Mip链。单边≤16384、总像素≤16777216。撤销/重做合计最多32步、历史像素128MiB；这不是进程总内存限制。预览纹理长边≤4096并受GPU纹理上限约束，输出使用完整像素。

## 诊断记录与验收边界

初始原生导出测试已定位一个固定依赖的输入边界：winit 0.29.15在原生对话框关闭后会抑制与上次完全相同位置的CursorMoved，而egui-winit在CursorLeft时清空位置；零距离返回可能让后续鼠标按钮事件丢失。测试通过真实2px移动重新进入保存按钮，再执行正常点击和原生另存，不直接调用保存函数。未修改依赖，也不声称修复所有系统对话框后的零移动输入。桌面焦点抢占会安全停止；文件名输入改为在已验证的自有对话框中一次Unicode批次，保留焦点检查。

窗口和像素验收范围为Windows、DPI96、浅深主题、880×560及1280×860；不声称Mac实机或所有DPI验证。最终构建、导出与主线复验结果在实际完成后追加。
