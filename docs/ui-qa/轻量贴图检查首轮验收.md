Task：`IV-TA-01`。2026-09-23 在 Windows x64、DPI 96（100%）的真实桌面程序上执行。输入均由脚本在忽略目录中新建；脚本使用隔离设置配置，结束后恢复原焦点和光标。截图 JSON 逐张记录源码提交、二进制 SHA-256、输入 SHA-256、逻辑/物理客户区、DPI、主题及动作。

## 代码与格式

- `cargo test --workspace --locked` 共 124 项、`cargo check --workspace --locked`、Windows 契约 24 项、macOS 边界 5 项通过。
- `crates/iv-core/tests/dds_dx10.rs` 使用标准 DXGI 数值及文件头测试 BC6H、BGRA/BGRX、拒绝不支持的类型、截断数据与标准 Mipmap 标志。标准标志值依据 [Microsoft DDS_HEADER 文档](https://learn.microsoft.com/en-us/windows/win32/direct3ddds/dds-header) 中的 `0x20000`。Volume DDS 各 Mip 必须跳过当前层级全部深度切片，依据 [Microsoft Volume DDS 布局](https://learn.microsoft.com/en-us/windows/win32/direct3ddds/dds-file-layout-for-volume-textures)；以首层、第二层、下一 Mip 分别不同颜色的样本验证，截断层级明确报错。
- 保留帧预算为 256 MiB（268435456 字节），包含另外保留的首帧；GIF/APNG/WebP/AVIF 统一限制，帧数最多 4096。该预算不包含解码器暂存或 GPU 副本。

## 轻量边界

- 没有新增运行时第三方依赖；保留单解码线程和有界队列。当前文件元数据每 500 ms 检查一次，稳定 300 ms 后通知界面；未打开文件时后台线程等待条件变量，不扫描目录树。
- 当前静态 CRT 测试版及 v0.6.0 正式版 `imageview.exe` 均为 25772032 字节（24.58 MiB）；v0.5.1 发布版：25478144 字节（24.30 MiB）；增量 293888 字节（0.28 MiB，1.15%）。正式版 hash 和打包数据见 `docs/releases/v0.6.0-validation.md`。
- 每组 880×560/1280×860 在已打开一张 480×320 PNG、关闭设置面板后，空闲稳定 1.5 秒，再以 1.5 秒间隔取 3 个样本；样本期间进程 CPU 增量为 0–0.016 秒，RSS 保持 232767488–235921408 字节。此数据包含整个 egui/wgpu 进程与 GPU 驱动相关的用户态资源，不能推断动画峰值、显存或其它机器的资源上限。
- 元数据检测无法辨别时间、大小、创建时间均不变的原地写入；F5 可强制刷新。BC6H 仍为 8 位预览，属性明确标识；16 位数据、ICC 和线性色彩管理不在本轮。
