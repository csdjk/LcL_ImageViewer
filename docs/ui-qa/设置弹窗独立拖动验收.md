# 设置弹窗独立拖动（IV-P1-N09）

用户澄清：拖动对象是查看器内部的设置弹窗，不是整个操作系统窗口。本轮覆盖N08错误的标题拖窗语义，不改变其他设置与画布鼠标操作。

## 实现

设置标题/顶部空白左键或右键只更新弹窗的客户区坐标，不调用原生WindowDrag/StartDrag。首次居中，当前会话关闭重开保留位置；边界留8点，缩小客户区或展开参数时约束弹窗。标题关闭按钮、正文、开关不参与拖动。画布右键仍移动整个查看器。删除设置专用的原生左键拖窗状态和构造函数。

## 分支验证

源码 `d15613601e2c6090ac3f2b55de57d223d1d9bd94`：40项测试、workspace check、Debug构建通过。四组DPI96、双主题/双尺寸实机回归共64张截图，位置/原生外框/像素检查通过。
证据：`ui-verify-shots/popup-drag-verified-{dark,light}-{880,1280}/`。
弹窗累计位移72×36、24×60、-12×36，原生窗口外框始终不变；左上越界约束和关闭重开位置、开关点击、正文无拖动、A/D均通过。关闭弹窗后画布右键移动原生窗口40×24成功，输入图片hash不变。已查看拖后和边界截图，无裁切/分类回归。
首次截图因标题悬停提示遮挡比较ROI而失败；测试移动指针离开弹窗后再取图复验通过，未降低阈值或修改产品逻辑掩盖失败。

## 复现

```powershell
python -B tools/ui-qa/settings_popup_smoke.py --binary target/debug/imageview.exe --output ui-verify-shots/popup-new-run --commit <当前源码commit> --theme dark --width 880 --height 560
```

N08的compact_settings_smoke.py包含“移动原生窗口”的旧预期，作为历史验收保留；当前设置拖动验收使用本入口。仅使用新建图片和隔离配置，不确认删除，不点击注册/系统设置，不关闭用户窗口。其他DPI、混合缩放及完整性能测试未覆盖。
