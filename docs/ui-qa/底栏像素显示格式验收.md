# 底栏像素显示格式与单通道联动

## 范围

任务 IV-P1-N17；基于包含顶部按钮精简的本地 v0.6.0。底栏坐标改为 `(x, y)`；设置新增“颜色显示格式”，支持 RGBA（0–1）、RGBA（0–255）和十六进制。默认及未知旧偏好回退到 HEX，设置由 `iv-pixel-format` 保存。

完整模式按 RGBA 显示；R/G/B/A 单通道仅显示当前分量名和值，色块同步显示该分量的不透明灰度。忽略 Alpha 模式显示 RGB。底栏读数仅做展示，源像素、完整像素检查器的原始 RGBA/HDR 浮点值、右键复制原始 HEX 均保留。

0–1 格式为解码后的 8 位分量除以 255，最多三位小数并去掉尾零；不进行额外的伽马变换、透明预乘或 HDR 映射。128/255 显示 0.502，不伪装成原始浮点 0.5。HDR 原始值仍在完整检查器查看。
