# 编辑器统一控件（IV-EDIT-03）

## 范围

本轮只统一主画布编辑器的外观和控件布局。没有修改 `app.rs`、`edit_ops.rs`、`image_edit.rs` 或 `iv-core`；裁剪、旋转、分辨率、历史和新文件保存语义沿用已验收实现。

`ui::editor_controls` 复用现有新拟态表面与主题：所有操作区高度 32 逻辑点、间距 8 点、圆角沿用 12 点。工具页签、文字按钮、输入框、下拉框、比例锁定和透明网格遵守相同的正常/悬停/按下/选中/禁用/键盘焦点规则。数值仍使用原生 DragValue；下拉仍使用原生 ComboBox，不自行重写输入和弹出行为。

应用和保存为主要动作；取消、返回、撤销为次要动作；放弃/丢弃使用语义性提示色。底部确认使用同一套按钮，提示行恒定为 40 点，避免出现待应用提示时挤压或重新居中画布。参数标签和数值输入按同一行高垂直居中。

## 可重复验证

- `cargo test --workspace --locked`：包含控件行高、禁用不改变几何布局、确认栏恒高及原编辑算法测试。
- `python -B -m unittest discover -s tools/tests -p 'test_*.py'`：控件接入和既有功能契约。
- `python -B tools/ui-qa/editor_controls_smoke.py --binary <当前程序> --commit <构建提交> --output <新目录>`：深浅主题、880×560/1280×860、四种工具、数值焦点、比例菜单、裁剪待应用提示、撤销重做、按钮悬停/按下，以及原生另存后的逐字节 PNG 核验。

GUI 脚本仅操作其启动的 PID 与独立 QA profile，使用生成的图片并另存新文件；不修改正常用户设置、原图或已安装程序。截图保留源码提交、二进制和输入哈希、窗口 PID、主题、DPI、尺寸和状态。
