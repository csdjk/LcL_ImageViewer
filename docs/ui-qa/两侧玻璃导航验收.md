# 两侧玻璃导航验收（IV-P1-N03，兼容 IV-P1-N02）

## 实现

源码提交 `76110145fae6a29be9f9e81e14a73f379705c3e9`，从独立N03工作树串行合并N02的1秒计时。
左右导航移到窗口左右边缘、垂直居中，距边18点，48×64点操作区，16点圆角。只对两侧按钮注册现有GPU真实场景模糊，其他新拟态面板不注册模糊，保留原样。不改变Shader、图像解码、取样或文件关联。
按钮正常/悬停/按下均半透明；第一张禁用上一张，最后一张禁用下一张，不循环。单图/空态不显示导航，菜单/设置打开时隐藏导航避免遮挡。

鼠标最后移动或点击后等待1秒开始淡出，动画保持120ms淡入/180ms淡出；按住时保持可见。第一轮窄窗口实机暴露连续点击时旧计时未重置的问题，已增加PointerButton事件计时重置和测试，最终四组均复验。
