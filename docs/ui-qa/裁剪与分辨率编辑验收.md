# 裁剪与修改分辨率验收

## 使用与边界

任务 IV-EDIT-01，基于包含顶部按钮精简和底栏像素格式的本地 v0.6.0。顶部编辑按钮、E 或右键菜单进入独立编辑窗口；拖框、移动选区、四角调整、X/Y/宽高输入，以及居中 1:1、4:3、16:9 裁剪；分辨率支持比例锁定、自由宽高、50%/100%/200%、双线性/最近邻。参数最多32步撤销/重做，重置不更改源文件。

默认另存新 PNG，拒绝覆盖原图和任何已有文件。后台先编码到自己创建的临时文件，再以不替换方式发布；不支持硬链接的文件系统使用 create_new，写失败清理自己的新文件。原生保存对话框属于本次查看器，不改置顶或用户默认关联；取消不关闭编辑窗口。编辑期间阻止底层切图、删除和自动刷新；关闭未保存编辑需确认，后台保存期间不能关闭编辑窗口。

编辑使用原始解码 RGBA 快照，不烘焙查看通道、棋盘格、曝光。无缩放裁剪和最近邻保留隐藏 RGB；双线性按 Alpha 加权以避免透明边缘混色。动画仅编辑当前帧并明确显示“静态PNG”，DDS取最高分辨率Mip0。输出8位RGBA，不保留原格式/图层/ICC/Mipmap；HDR浮点拒绝编辑。编辑输入/输出单边最多16384，总像素最多16777216。预览缩放显示，不承诺ICC或全HDR编辑。
