# 自定义背景调色板

## 交互

顶部背景菜单 → 自定义颜色。原三个 RGB 滑条改为二维选色区域、彩虹色相条、颜色预览、六位 HEX 输入及八个快捷色块。左右选择饱和度，上下选择明暗；色相单独保存，黑白灰状态不会丢失之前的色相。色板和色相条支持点击、拖动以及聚焦后的方向键微调。

选择即时反映到画布，不修改图片和通道数据。有效色号可带 `#` 或不带；不完整或非法输入保留上次有效颜色，并禁止应用。Enter 或“应用并关闭”确认；返回箭头回到背景预设，Esc 或点击面板外关闭。关闭不撤销已经预览的颜色，与原背景菜单保持一致。

自定义面板独立替换预设列表，不把大色板堆在六个菜单项下；保持原顶部布局和 880×560 最小窗口。继续使用 `iv-background-color`、`iv-checkerboard` 保存选择，不改变置顶/主题/解码与文件关联，不增加依赖。

所有实机操作只针对脚本启动的窗口，使用合成图片与隔离 QA 配置，原用户图片/偏好/安装不变。当前执行结果及主线提交由集成复验补记。
