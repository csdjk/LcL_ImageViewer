# 顶部置顶与背景颜色菜单验收

## 功能与边界

顶部新增图钉开关：通过原生窗口层级保持在普通窗口上方，默认关闭，保存用户选择；切图、最小化/恢复和调整窗口大小不取消置顶。文件选择对话框明确归属于当前查看器，继承正确层级；修复取消文件选择时 Esc 穿透到查看器退出快捷键的问题。

顶部背景按钮展开菜单：棋盘格、跟随主题、白色、灰色、黑色、自定义 RGB。原设置页“透明背景”切换移除。颜色只影响画布和透明合成，不改图片、通道取样或界面主题。菜单展开期间保持入口可见；Esc/点击外侧关闭，自定义拖动不移动主窗口。显式颜色暂不使用桌面磨砂，但保留用户原来的磨砂开关；切回跟随主题后仍可使用。

新增偏好键 `iv-always-on-top`、`iv-background-color`；兼容旧 `iv-checkerboard`。非法颜色回退到主题，用户颜色在 CPU 画布和 GPU 合成中保持相同的 RGB 数值。复用依赖锁中既有 raw-window-handle 0.5.2 作为 rfd 父窗口适配，不升级依赖版本。

## 可重复验收

常规执行 `cargo test --workspace --locked`、`cargo check --workspace --locked` 和 `python -B -m unittest discover -s tools/tests -p "test_*.py"`。

正式运行验证使用 `tools/build_windows_release.py --target-dir <独立目标目录>` 构建；Rust/CMake/NASM 只加入本次进程 PATH，不修改全局环境。

`tools/ui-qa/topbar_controls_smoke.py` 使用新建图片和隔离偏好，覆盖原生 WS_EX_TOPMOST、与本次创建的普通窗口的实际 Z 序、最小化/恢复、切图、原生文件对话框取消、背景 RGB、通道像素、菜单关闭/自动隐藏/恢复、设置及保存值重新加载。参数：

- 880×560：`--background-x 611 --pin-x 693 --settings-x 647`。
- 1280×860：`--background-x 902 --pin-x 1020 --settings-x 974`。
- 其他必需参数：`--binary <当前imageview.exe> --output <新目录> --commit <提交> --theme light或dark --width <宽> --height <高>`。

`tools/ui-qa/topbar_layout_smoke.py` 覆盖带动画工具栏的 880/1000/1119/1120/1199/1200/1280 宽度及空窗口；明确要求工具栏可见，避免把隐藏截图误当成布局证据。另用 `animated_avif_smoke.py` 验证播放/暂停、逐帧及通道回归。

## 不覆盖的范围

本轮实机在 DPI 96 / 100% 缩放下验证；未把其他 DPI、特殊全屏窗口或其他置顶程序之间的层级宣称为已测。未修改用户原图、已有偏好、安装目录和文件关联，不推送、不打包或发布新版本。测试仅操作自己的新进程、测试窗口和独立偏好命名空间。
