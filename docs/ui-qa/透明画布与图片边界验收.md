# WebP / PSD 预览、透明画布与图片边界（IV-P1-N10）

## 行为

- WebP 加入可选资源管理器缩略图注册。PSD 和其他旧缩略图槽的 GUID 字面量移除多余的右花括号；打开方式登记与缩略图登记不是同一项功能。
- 缩略图单独解码动画第一帧，不再为了预览收集全部动画帧。PSD 的 RAW / RLE 合成图路径保留，并修正带额外蒙版通道时 RLE 行长度表的偏移。
- 缩略图缩小时按 Alpha 加权颜色，避免透明像素隐藏颜色污染边缘；输出保持 straight BGRA，不改变查看器原像素。HDR 只映射 RGB，不再把 Alpha 当作亮度映射。
- 棋盘格在透明图片的整个画布内绘制；图片外与内部透明区域共用屏幕坐标原点。格子固定为 8 逻辑点，不随图片缩放，深浅主题分别配色。纯色选项仍可用，未带 Alpha 的 JPEG 不强制显示网格。
- 顶部“显示图片边界”开关，快捷键 B，默认关闭，保存到原有配置中的 `iv-image-bounds`。边界是当前图片 / Mip 的完整矩形，包含透明留白，不是内容轮廓；跟随缩放平移，位于图片之上、弹层之下。边界不写回图片，不参与像素取样。
- README 只补充对应功能行与快捷键，保留精简用户首页结构。

## 缩略图缺失诊断

只读检查发现旧安装实际登记的缩略图子键是 `{E357FCCD-A995-4576-B01F-234630154E96}}`，多一个结尾 `}`，正确子键不存在；WebP 也不在缩略图扩展名列表中。CLSID 本身存在，指向用户 D 盘安装，因此单独测试 DLL 能工作并不能证明 Explorer 注册正确。

原隔离安装测试曾从安装脚本推导预期字符串，未发现双右括号错误。本轮增加独立的 Windows GUID 断言，同时在真实 Inno 隔离安装结果中读取固定正确的 PSD / WebP 槽。关联记录数由 71 变为 72；缩略图格式数由 8 变为 9。

相关接口依据：Inno Setup Constants（开括号需转义，闭括号不双写）、Microsoft IThumbnailProvider::GetThumbnail、Windows-classic-samples 的 RecipeThumbnailProvider；PSD 行长度表依据 Adobe PSD Image Data Section。

## 工作分支验证

功能及验证源码截至 `1ecd448`。原 main 基线 `f094a58`，原先三个未推送的 README 提交完整保留。

- `cargo test --workspace --locked`：62 项通过。
- `cargo check --workspace --locked`、Debug / Release workspace 构建通过；仅原 iv-shell 导出可见性 LNK4104 警告保留。
- `python -B -m unittest discover -s tools/tests -p 'test_*.py'`：12 项通过，含独立标准 GUID 与脚本扩展名一致性检查。
- 直接载入当前 DLL，通过真实 IInitializeWithStream / IThumbnailProvider 获取 PNG、静态 WebP、动态 WebP、RAW PSD、含额外通道 RLE PSD、JPEG 的 128 / 512 两档预览，共 12 个有效 HBITMAP。大于原图的请求不放大。
- PNG / 静态 WebP / 两种 PSD 对比 6 组完整 RGBA 一致；动态 WebP 对比 2 组可见 RGB 和 Alpha 一致。动画合成会清空 Alpha 为零区域的不可见 RGB，未把它误记为所有底层字节相同。
- 真实 Inno 安装 / 卸载测试重定向到独立 HKCU InstallerQA 命名空间，确认 72 个字符串值与正确 PSD / WebP GUID；用户实时注册项快照前后不变。
- 四组实际 Windows GUI 回归：浅色 / 深色 × 880×560 / 1280×860，DPI96，80 张截图。全画布网格连续、图片边界完整、平移与缩放跟随、Alpha / 忽略 Alpha、纯色与网格恢复、设置遮挡、同目录格式切换和偏好保存通过。880 两主题实际点击顶部边界按钮，确认可开关。
- 检查原图内部区域：开 / 关边界不改变内部像素；PNG、WebP、PSD 的对应显示一致。未操作或删除用户图片。

实际截图已检查：顶部按钮和提示、深浅棋盘格、完整边界、设置弹层以及实际缩略图输出。早期自动点击失败是悬停截图耗时超过 1 秒自动隐藏，改为点击前先移动唤回工具栏；失败批次不计入最终通过截图。

## 部署与限制

本轮只修改源码、构建开发版及验证，不修改用户实际安装、实时缩略图注册或系统默认应用，不推送、不重新打包或发布。当前正式 v0.3.1 的安装包不会因此自动更新。Explorer 中启用修复还需要后续更新安装包 / 安装目录中的 DLL，并正确登记缩略图组件；“设置 → 打开方式 → 注册”不能代替缩略图登记。

PSD 仍以支持的 RGB / 灰度 RAW / RLE 合成图为准，不承诺 ZIP / CMYK / PSB 等未实现变体。未覆盖多 DPI / 混合屏、生产环境 Explorer 缩略图缓存和全部权限组合。直接 COM 和隔离安装验证不等同于已替用户安装并看见 Explorer 中的预览。

主线集成与当前二进制记录在完成主线重建、复验后补充。
