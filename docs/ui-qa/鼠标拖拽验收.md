# 鼠标拖拽验收（IV-P1-N04）

用户于2026-09-14要求：左键拖拽图片，右键拖拽整个窗口。

## 实现

- 画布左键拖拽平移图片，不移动窗口；中键平移继续兼容。起拖时补齐阈值判断之前的位移，保持跟手。
- 画布及顶部工具栏空白处可右键拖动窗口。右键单击仍打开画布菜单；右键拖出再拖回原位也不误弹菜单。Esc可取消正在进行的右键拖窗。
- 当前winit 0.29.15的系统拖窗入口发送WM_NCLBUTTONDOWN，不能直接作为右键手势实现。本轮使用当前进程自己的HWND、屏幕物理坐标锚点及SetWindowPos(NOSIZE|NOZORDER|NOACTIVATE)，不模拟左键、不操作其他窗口。松键/失焦/API失败结束移动；全屏/最大化下不移动外层窗口。
- 保留顶部空白左键标题栏拖动、左键窗口边缘缩放、滚轮缩放、两侧玻璃导航、1秒隐藏和图像解码/着色器/取样逻辑。不改文件关联、快捷方式或安装目录。
