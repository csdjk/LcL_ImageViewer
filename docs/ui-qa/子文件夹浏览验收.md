# 子文件夹图片浏览（IV-P1-N11）

## 用户操作

顶部“打开”按钮右侧新增目录树图标：**包含子文件夹**。点击图标或按 `S` 切换。每次启动默认关闭，避免打开一个文件时无意间扫描很大的目录。模式切换不会重新解码正在显示的图片。

开启时，以当前图片所在目录为固定根；当前目录和其所有可访问普通子目录进入同一个导航列表。两侧按钮、A/D、方向键、PgUp/PgDn、Home/End 均使用此列表。按相对路径排序，不越过列表首尾。

普通切图、进入孙目录、删除后切换图片均不改变固定根。关闭后仅浏览当前图片所在目录；再次开启以当时图片目录重新定根，不会自动升到原来的上层目录。通过打开对话框或拖入文件显式打开另一张图片时，开启一个新的浏览范围。

数量栏使用固定宽度，扫描进度/单张图片/部分结果之间切换不会移动左侧开关。悬停在图标或数量上可查看根目录、当前相对路径、扫描进度和跳过原因。

## 范围与资源保护

- 单独后台线程建立路径索引，不在扫描阶段解码所有图片；完成后一次性发布排序列表。扫描时保留当前图片；新范围的子目录列表在扫描结束后可用。
- 新请求覆盖旧请求并通过 generation 取消旧扫描；进度最多每100ms更新，邮箱最多保存一个结果，避免积累大量全量快照。
- 单次最多收录50,000张图片；路径及排序临时开销保守预算32 MiB；最多检查250,000项、10,000个目录，深度最多64层，扫描时间预算15秒。
- 超限后保留已找到的图片，数量后显示“部分”；悬停说明具体限制，提示打开更小的文件夹。权限错误、过深目录同样报告，不把部分结果冒充全部。
- 不跟随符号链接、Windows junction、挂载点等重解析点。每个子目录使用前再次检查属性及 canonicalize 后是否位于固定根内，避免父目录回环和链接越界。用户明确打开的根本身允许解析为实际目录。
- 保留相邻最多4个预读请求和192 MiB解码缓存预算；不是进程总内存上限，当前超大图片、解码临时缓冲和GPU纹理另计。旧范围的预读结果不会继续填入新范围缓存。
- 删除后的目录更新也在后台进行；确认回收成功后先从旧索引移除目标并显示相邻图，再按原固定根刷新。过期扫描结果不能把删除目标重新加入当前列表。

取消和15秒预算为协作式：正在执行的一次文件系统调用不能强行中止，网络盘、异常磁盘可能超过预算；界面线程不等待其退出。此功能不包含后台常驻服务、跨进程缓存、目录实时监控或向上搜索。

## 验证入口

`cargo test --workspace --locked` 包含非递归/递归范围、父级与同级根外排除、真实junction回环、无效/不可访问路径、各预算边界、取消与最后请求优先，以及5,004项只索引路径、不解码内容的测试。

真实窗口脚本：

```powershell
python -B tools/ui-qa/subfolder_browse_smoke.py --binary <当前imageview.exe> --output <新建证据目录> --commit <提交> --theme light --width 880 --height 560
# --button-x <实际图标横坐标>：通过真实顶栏按钮而非快捷键切换
# --delete-case：只回收本脚本新建的子目录图片，并核对回收站SHA256
```

所有图片、父目录诱饵和junction均由用例新建；不改变实际安装、系统关联或已有用户文件。深浅主题、880×560与1280×860使用隔离QA配置；原始PNG和元数据保存在 `ui-verify-shots/n11-*`。
