# v0.3.1 — 加载加速与安装器修复

本版本将近期已验证的加载优化、默认 D 盘目录和“打开方式”修复统一打包。

## 更新内容

- **更快打开图片**：首图解码与窗口/GPU初始化并行；目录扫描放到后台，同目录切图复用列表；最新选择优先处理，预读去重且有限，减少像素缓冲重复复制。原始尺寸、Alpha、Mip、HDR和现有显示规则保持不变。
- **修复打开方式注册**：v0.3.0安装包遗漏注册值类型，可能只创建空键并残留旧路径。v0.3.1补齐应用名称、支持格式和打开命令等71个字符串值，安装后通知资源管理器刷新。安装时需勾选对应任务，不强制修改系统默认应用。
- **默认安装到D盘**：新安装优先 `D:\Program Files\LcL ImageViewer`；没有D盘时回退 `%LOCALAPPDATA%\Programs\LcL ImageViewer`。升级仍沿用原目录，目录选择页保持可修改，不自动搬迁已有安装。
- **静态WebP修复**：静态图不再走动画帧收集分支，避免“动画无有效帧”错误。

## 升级提示

关闭旧查看器，再运行安装包。修复“打开方式”时保留对应选项勾选，并从实际安装目录启动；不要把开发目录的Debug/Release副本注册成默认打开程序。老安装可能仍显示原来的H盘目录，这是升级沿用旧位置；需要变更时在向导中手动选择。桌面和开始菜单若仍指向其他副本，需检查目标路径。

## 验证范围与限制

发布前重新执行代码测试、安装器检查及隔离的真实Inno注册写入/卸载验证，并检查正式包版本、文件完整性与程序启动。验证详情见仓库 `docs/releases/v0.3.1-validation.md`。

性能改善来自流程优化，不保证所有文件都瞬开。此前同机、同输入、每种5次新进程且文件缓存已热的对比，CPU首次绘制提交耗时约降低13%–25%；这不是冷盘或显示器完成呈现时间。超大PSD/DDS/HDR及长动画仍可能等待。更完整的方法与限制见 `docs/performance/image-loading.md`。

安装包未配置代码签名；不承诺已完成所有DPI、多屏、权限或全部安装/卸载环境回归。安装器注册回归在隔离命名空间执行，没有在用户当前安装上自动重装或改写默认关联。旧v0.3.0标签与附件保持不变。
