# v0.3.0 — 新拟态界面与交互升级

## 界面

- 全面更新深浅主题：雾蓝灰新拟态控件、柔和阴影与选中/按下反馈。
- 上一张/下一张移至窗口两侧，使用半透明场景模糊材质。
- 悬浮工具栏静止1秒后开始淡出，移动或点击后恢复。
- 右键菜单和设置页改为无分类紧凑列表，保留常用功能。
- 设置弹窗支持标题左/右键独立拖动；主窗口保持不动，并限制弹窗在客户区内。

## 操作与修复

- 新增 A/D 切图，保留左右方向键；画布左/中键拖图、右键拖动主窗口。
- 修复 Delete 无响应：确认后将当前图片移入回收站，取消不修改文件。
- 删除后同步导航与缓存；显示下一张、末尾回退或回到空态。不提供永久删除回退。
- “打开所在文件夹”直接打开当前图片父目录，改善中文、空格等路径处理。
- 设置开关、滑条和关闭按钮不再误触发拖动；输入框和弹层有快捷键保护。
- README 配图更换为本版本实际运行截图；纠正 PgUp/PgDn 为切图、上下方向键为 Mip 的说明。
- 免安装包缩略图脚本可直接找到同目录 DLL，解除注册时仅移除本扩展占用的处理器。

## 下载

- `LcL-ImageViewer-Setup-v0.3.0-win64.exe`：Windows x64 安装版。
- `LcL-ImageViewer-v0.3.0-win64.zip`：免安装版，解压后启动 `imageview.exe`。
- `SHA256SUMS.txt`：上述文件的 SHA-256 校验值。

升级前关闭旧版本。不要将开发目录或旧安装目录中的其他 EXE 误认为已升级。
