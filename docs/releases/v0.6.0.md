# v0.6.0 — 轻量贴图检查

本版面向游戏开发和技术美术的日常贴图检查：保存当前图片后自动刷新，坏文件或保存中断时保留上一有效画面并显示错误；按 F5 可强制重读，按 L 可锁定切图时的缩放和平移。设置中可开关自动刷新与视图锁定，选择会保存。

DDS 修正了 BC6H、BGRA/BGRX、标准 Mipmap 标志与体积贴图后续层级的切片偏移。BC6H 仍显示 8 位预览，属性里明确说明它不保留浮点 HDR 值。GIF、APNG、WebP、AVIF 动画采用统一的 256 MiB 保留帧像素预算，超限明确报错。程序未增加运行时第三方依赖。

## Windows x64 下载

- `LcL-ImageViewer-Setup-v0.6.0-win64.exe`：安装版。
- `LcL-ImageViewer-v0.6.0-win64.zip`：免安装版，解压后运行 `imageview.exe`。
- `SHA256SUMS.txt`：附件 SHA-256 清单。

升级前请关闭旧版本。安装包不会自动更改默认看图软件。普通看图无需注册资源管理器缩略图扩展；需要时可在安装时选择或手动注册。

本次正式附件仅包含 Windows x64。仓库继续保留 macOS 预览构建流程，未将旧预览包改名作为 v0.6.0 发布。
