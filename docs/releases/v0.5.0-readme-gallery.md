# v0.5.0 README 功能图解制作

11组功能介绍分别对应10张静态图和1段真实窗口录屏GIF。素材仅项目自有图标与生成的AVIF/PNG/WebP/PSD/DDS/HDR测试文件；不捕获系统文件选择器、私人路径或桌面。

截图源码提交 `eef7303703724512aaa48fd3f79b733d1a9c57ee`，应用版本0.5.0。图像只做裁剪、缩放、压缩和截图外标题，未重绘UI。RGBA是同一图片的6种通道状态；动图在真实窗口中播放、暂停、逐帧及恢复。像素检查在完整截图下附原生检查器读数局部。缩略图来自真实DLL直接COM输出，不模拟Explorer。

原始截图、交互步骤和DPI元数据保存在忽略目录 `ui-verify-shots/release050-features`、`ui-verify-shots/release050-pixel-details`；公开图片逐项来源保存在 `docs/screenshots/features/v0.5.0/manifest.json`。公开截图均DPI96，880×560/1280×860；不宣称完整多DPI测试。

可复现入口：`tools/ui-qa/feature_gallery.py`、`export_feature_gallery.py`、`feature_thumbnails.py`。像素检查器完整读数的补充截图在上述独立目录；导出清单记录额外裁剪。README每个三级功能标题必须跟配图，GIF内容、图片路径、来源和包体预算有自动测试。

截图阶段未观察到合成wheel事件改变缩放，相关图片只标注已实际显示的最近邻采样与边界，不将其作为滚轮缩放验收。原生图像拖动截图和读取采样功能不受此文档制作限制影响；本次未改动查看器业务代码。
