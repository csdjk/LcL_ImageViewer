# v0.5.1 — 圆形左右切图按钮

这是 v0.5.0 的小版本视觉更新，主要调整图片查看时窗口两侧的上一张 / 下一张按钮。

## 更新内容

- 左右切图按钮由 48×64 圆角矩形改为 56×56 真圆形。
- 圆形玻璃模糊遮罩、边缘高光、阴影与焦点轮廓保持一致，不再残留竖向胶囊轮廓。
- 保留上一张 / 下一张点击、首尾禁用状态、悬停反馈和 1 秒自动隐藏 / 恢复。
- 其余功能与 v0.5.0 保持一致，包括 RGBA 通道查看、GIF/APNG/WebP/AVIF 动画播放与逐帧、DDS/TGA/PSD 等格式、背景调色板、置顶和资源管理器缩略图。

## Windows 下载

- `LcL-ImageViewer-Setup-v0.5.1-win64.exe`：Windows x64 安装版。
- `LcL-ImageViewer-v0.5.1-win64.zip`：免安装版。
- `SHA256SUMS.txt`：发布附件完整性校验。

升级前请先关闭旧版本。本次发布不会自动替换当前已安装程序，也不会擅自修改系统默认看图软件。

## macOS

仓库中的 Apple Silicon / Intel macOS 预览构建流程继续保留；本次 v0.5.1 Release 发布的正式附件为 Windows 版本，不把此前 v0.5.0 预览 DMG 改名冒充 v0.5.1。
