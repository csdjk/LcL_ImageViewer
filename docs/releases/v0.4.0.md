# v0.4.0 — AVIF 动画与图片浏览增强

## 新增与改进

- **AVIF 静态及动态图片**：支持透明通道，动画自动循环播放；可播放/暂停、前后逐帧，宽窗口可拖动帧进度。保留每帧时长、Alpha，以及容器裁剪、旋转和镜像。
- **子文件夹浏览**：顶部开关或 `S` 开启，只向当前目录下查找；左右按钮、A/D 与方向键可跨子目录切图。顶部显示图片相对于浏览根目录的路径，悬停查看完整路径。
- **透明图检查**：棋盘格铺满画布；顶部按钮或 `B` 高亮图片完整边界，包含透明留白并跟随缩放、平移。
- **缩略图修复**：补齐 WebP、AVIF 缩略图支持，修复 PSD 缩略图注册与部分附加通道文件的读取；动画缩略图仅解码首帧。
- **稳定性**：修正动画计时的累计误差；目录扫描可取消且有资源限制，AVIF 动画按总解码数据量检查预算。
- **用户文档与打包**：README 按当前功能整理；安装包与免安装包包含新增解码库的许可文件。

## 下载与升级

- `LcL-ImageViewer-Setup-v0.4.0-win64.exe`：Windows 10/11 x64 安装版。升级沿用原目录；需要资源管理器预览时，安装时勾选缩略图。
- `LcL-ImageViewer-v0.4.0-win64.zip`：免安装版，解压后运行 `imageview.exe`，普通看图无需注册 DLL。
- `SHA256SUMS.txt`：安装版与 ZIP 的 SHA-256 校验值。

升级前请关闭旧版本。软件不会自动抢占系统默认打开方式；已有快捷方式应指向新安装目录或新解压目录。

## 已知范围

AVIF 10/12 位输入转换为 RGBA8 显示，暂不提供 AVIF HDR 映射及 ICC 色彩管理。动画按查看器方式循环播放，暂不按文件中的有限循环次数自动停止。AVIF 输入上限 128 MiB、4096 帧，整段动画 RGBA 数据（含首帧副本）预算 256 MiB；超限会明确报错，不静默截帧。预算不是进程总内存上限。

本版本未做代码签名。验证使用真实 Windows 桌面、100% 缩放、合成测试素材及隔离安装环境；其他 DPI、跨屏和全部生产文件变体未全覆盖。
