# v0.8.0 — 壁纸与资源管理器排序

- 右键新增“设为桌面壁纸”，使用原图像素，动画取当前帧，透明区域合成为黑色；支持成功与失败提示。
- 单目录切图优先跟随资源管理器当前排列，支持名称、修改日期、大小以及升降序。
- 右键新增“刷新文件夹排序”；改变资源管理器排序后可立即更新，悬停可查看当前排序来源。
- 未找到对应窗口时按自然文件名排序（1、2、10）；包含子文件夹时按相对路径自然排序，多窗口冲突或读取失败会说明原因。
- 修正小窗口右键菜单跳动以及壁纸结果提示被顶栏遮挡的问题。

壁纸应用到所有显示器并保持系统布局；HDR浮点图片暂不支持。资源管理器未显示的新文件排在末尾；虚拟目录、跨窗口冲突及其他DPI组合不保证完全覆盖。

升级沿用原安装目录与选项，用户偏好和原图保留。本次发布Windows x64安装版和便携版；macOS预览版不更新。
