# v0.7.0 — 主画布编辑与离线 OCR

这版把常用图片编辑和文字识别加入查看器，同时整理了像素读数与操作控件。

## 主要更新

- **直接在图片窗口编辑**：按 E 进入主画布编辑；支持拖动/精确裁剪、八个边角手柄和固定比例，左右 90° / 任意角度旋转、水平 / 垂直翻转，以及真正修改像素分辨率。提供比例锁定、常用倍率、平滑 / 最近邻采样、撤销 / 重做 / 重置。编辑控件已统一为新拟态样式。
- **本机 OCR 与文字复制**：顶部文字识别按钮查看结果；Ctrl+Shift+C 或右键“识别并复制图片文字”直接复制。支持选择已安装的识别语言、校对结果、复制全文、保留换行或合并成一行。中文识别结果中的相邻汉字分词空格已整理。
- **像素信息更清晰**：坐标显示为 `(x, y)`；设置中可选 RGBA 0–1、RGBA 0–255 或十六进制。R / G / B / A 单通道下只显示当前通道读数，色块同步为灰度。顶部保留“实际大小”，移除重复的适配按钮；F 快捷键仍可适配窗口。
- README 已补齐编辑与 OCR 使用说明、快捷键及实机配图。此前的 AVIF 动画、RGBA 通道、TGA / DDS / PSD、文件保存后刷新、背景调色板与置顶功能保留。

## 使用与边界

编辑只会**另存新的 8 位 RGBA PNG，不覆盖原图或已有文件**。视图放大缩小不改变图片像素尺寸。动画编辑 / OCR 取当前帧；DDS 使用 Mip 0。编辑输出不保留图层、ICC 或 Mipmap，HDR 浮点暂不编辑 / OCR。

OCR 使用 Windows 本机系统组件，不上传图片、不需要 API Key，也不额外下载模型。识别语言取决于系统已安装的 OCR 语言组件；“自动”表示系统语言，不是自动判断图片语言。系统组件缺失或不支持时会明确提示。复杂背景、艺术字及相似英文字符可能识别错误，可校对后复制；本机测试不代表所有 Windows 安装环境都支持。

## Windows x64 下载

- `LcL-ImageViewer-Setup-v0.7.0-win64.exe`：安装版。
- `LcL-ImageViewer-v0.7.0-win64.zip`：免安装版，解压后运行 `imageview.exe`。
- `SHA256SUMS.txt`：附件完整性校验。

升级前关闭旧版本。安装不会擅自更改系统默认看图软件，普通看图不需要注册资源管理器缩略图扩展。

本次正式附件仅包含 Windows x64；macOS 仍保留原预览构建流程，尚未接入 OCR。本次没有发布新的 macOS DMG，也没有将旧预览包改名。
