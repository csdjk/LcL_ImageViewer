# v0.5.0 — 置顶、调色板与图文功能说明

顶部图钉让查看器保持在普通窗口上方，切图、最小化恢复及重启后保留选择。背景颜色可直接从顶部切换；自定义颜色新增二维色板、彩虹色相条、HEX色号输入和快捷色块，拖动时实时预览。

修复置顶时文件选择对话框被遮挡，以及按Esc取消文件选择时意外退出查看器的问题。保留RGBA单通道、像素检查、动态AVIF/GIF/APNG/WebP、子目录浏览、图片边界与资源管理器缩略图。

README按功能配上当前版本实机截图，并提供播放、暂停和逐帧演示。

## 下载与升级

- `LcL-ImageViewer-Setup-v0.5.0-win64.exe`：Windows x64安装版。升级前关闭旧版，沿用已有目录；需要缩略图时勾选对应安装选项。
- `LcL-ImageViewer-v0.5.0-win64.zip`：免安装版，解压运行`imageview.exe`。
- `SHA256SUMS.txt`：下载完整性校验。

不会自动替换正在运行的旧开发EXE或更改系统默认看图软件。保留旧版附件。

## 已知范围

AVIF高位深转8位显示，暂不支持AVIF HDR映射、ICC色彩管理或按文件有限循环次数自动停止。PSD仅已保存的合成图，不支持图层编辑/PSB。未配置代码签名；尚未完整覆盖混合DPI、多显示器及全部生产安装环境。
