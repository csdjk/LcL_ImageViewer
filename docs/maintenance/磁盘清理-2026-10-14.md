## 复核方法

本地审计目录：`Temp/storage-cleanup-20261014/`。`before.json`保存逐文件SHA-256/字节数、明确删除清单、分支和工作树快照；`cleanup.ps1`在PowerShell中检查每个绝对目标是主工作区target的直接子项，验证显式白名单、Git忽略、无跟踪文件和重解析点、无构建/查看器进程，再用`Remove-Item -LiteralPath`删除并记录`deleted.json`。没有使用全仓`git clean`。

在任务提交前执行：

```powershell
python -X utf8 Temp/storage-cleanup-20261014/verify.py
git diff --check
```

`verify.py`重新枚举保留区域，逐文件SHA-256比较，核对没有遗漏/新增/内容变化、删除清单全部消失、所有41个工作树（主工作区、39个历史任务及本次临时任务）和分支引用与删除前一致，并独立核对v0.7.1安装包和ZIP的SHA256SUMS。审计目录自身及会被Git命令更新的.git内部文件不参与内容哈希比较；逻辑体积统计包含.git，不包含审计目录自身。

本轮没有修改Rust、运行逻辑或UI，因此没有重新运行Cargo构建、单元测试或GUI矩阵；通过内容哈希验证源码/既有正式产物保真，避免重新生成刚删除的缓存。不把历史运行证据算作本轮应用测试。
