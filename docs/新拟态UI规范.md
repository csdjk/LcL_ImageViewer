# 新拟态 UI 规范

用户于 2026-09-14 指定的新视觉方向。本规范替代旧玻璃方案中的材质、配色和装饰边框参数；原有真实桌面验收及图片功能保真要求继续有效。

## 视觉合同

- 主风格：浅色雾蓝灰单色系，主表面 `#E6EBF2`，画布 `#E9EEF5 → #E1E7F0`，正文 `#34445B`。深色使用同色相的深浅变化，保留 T 切换及已保存的主题。
- 圆角：操作控件 12、分组卡片 14、面板 16 egui 逻辑点；圆形开关滑块和矢量图标不套用矩形圆角。
- 光源：左上。凸起表面使用左上柔光、右下柔影及低强度接触阴影；常态低凸，悬停略抬高；按下与选中使用同色系内凹底和沿圆角衰减的内阴影。
- 不画装饰硬边框和分隔线。仅保留有语义的键盘焦点细轮廓及柔和光晕；禁用控件去除浮起效果。
- 工具栏、通道、菜单、设置卡片、开关、文字按钮和格式标签统一材质。RGB/R/G/B/A 不再靠不相关彩色底区分；原图和像素颜色样本保持真实数据。
- UI 表面不透明。桌面磨砂仍是可选画布功能；新安装默认关闭，已有显式开启的设置继续保留。已保存的深色偏好不会被强制清除。

## 实现与边界

`ui.rs` 管理 Palette、12/14/16 圆角、NeuFrame、多层 Shadow 和圆角内阴影网格；`app.rs` 仅更新默认值、组件调用及材质说明。没有修改图像解码、着色器、原始像素取样和 Windows 文件关联逻辑。

阴影使用 epaint 0.27.2 原有 tessellation，不增加依赖或每帧 CPU 图像模糊。内阴影采用 7 层 × 36 顶点并衰减到透明；布局保持原有 32 点操作高度。性能尚须专项测量，不宣称具体帧率/GPU 毫秒数。

## 验证

新增测试覆盖默认浅色、双主题面板不透明度与正文对比度、圆角范围、内阴影网格边界及衰减。执行 `cargo test --workspace`、`cargo check --workspace`、`cargo build --release -p iv-viewer`。

真实桌面截图入口：`tools/ui-qa/neumorphic_smoke.py`。截图与运行元数据写在根工作区忽略目录 `ui-verify-shots/`，最终覆盖及限制见 `docs/ui-qa/新拟态验收.md`。单色系理论对比度测试不等于所有图像、所有 DPI 的视觉门禁；本任务不把整个 P1 阶段标记为 VALIDATED。
